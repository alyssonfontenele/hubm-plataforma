## Premissas
1. O quadro (`GET /pedidos`) não traz o id da coleta no cartão; o front cruza com `GET /coletas` (todos os papéis veem) para achar a coleta de cada pedido. Se `/coletas` falhar (ex.: 503 de ambiente sem expedição), o quadro segue sem as ações de coleta.
2. "Quem busca" é transportadora do cadastro (`/transportadoras`) ou veículo próprio (placa e motorista opcionais; formato da placa conferido pela API).
3. Remarcar pelo lojista volta a coleta a SOLICITADA (contrato J663); a tela avisa.
4. Documento com arquivo é baixado por `fetch` com o JWT e salvo como blob (não há link público). NF-e "automática" (ligada pela chave) não tem arquivo: mostra número e chave.
5. O dublê reproduz o contrato lido no código da J663; não foi comparado com a API real rodando.
